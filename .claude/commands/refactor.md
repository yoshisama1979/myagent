プロジェクトルートで `git diff --staged` を実行してステージ済みの差分を確認し、[rules/refactoring.md](../../rules/refactoring.md) のガイドラインに従ってリファクタリングを行ってください。

特に次の3点を守ること（このリポジトリ固有の事故が実際に起きている箇所です）：

1. **既定スコープは STRICT**＝差分に含まれるファイル・行だけ。差分を超える改善は同ルール §7 に従い、その場で直さず実測値つきで起票する。
2. **複数エージェントが同じ作業ツリーに同居している**＝`git add .` を使わず pathspec で自分の分だけをステージし、`git diff --cached --stat` で混入を毎回検査する（§4）。
3. **挙動不変は「示す」**＝関連する回帰スイートを流し、読み取り専用ツールは前後の出力一致を確認してからコミットする。示せないならやらない（§5）。

リファクタリング不要という結論も正しい結論です。無理に変更を作らないでください。
