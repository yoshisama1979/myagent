# /triage — 残課題の仕分け

**まず読む**：[rules/modes/triage.md](../../rules/modes/triage.md)（このモードの正）

## これは何のためにあるか

無人ループは毎日「気づいたこと」を起票するが、**閉じる仕事は誰のものでもなかった**。
その結果、台帳が合計 985KB まで膨らみ、ヘッドレスの25分制限に当たり始めた。
中身を数えると、いちばん太い台帳は **71%が「社長の回答待ち」**で、
退避で減らせるのは9%だけだった（2026-08-27 実測）。
**太る原因はゴミではなく、決まらないまま積み上がった案件そのもの。**

だからこのモードの仕事は「片付ける」ではなく **「決める場を1つにする」**。

## 起動時にやること（この順に）

0. `bash bin/office-beacon.sh start triage "残課題の仕分け" "" cmd-triage` — 3Dオフィスの机を点灯
   （見た目専用＝失敗しても本作業は続ける。TTL=10分なので、長丁場は区切りごとに同じコマンドで延長）
1. `python3 bin/pending-scan.py scan` — 走査して状態を更新する
2. `python3 bin/pending-scan.py stats` — レーン別の件数と、**取りこぼしの件数**を必ず社長に見せる
3. `python3 bin/pending-scan.py list --status open --limit 40` — 中身を読む

## 社長に出す前に、AI が3つに仕分ける

| 区分 | 中身 | 出口 |
|---|---|---|
| **A. 社長にしか決められない** | 値付け・優先順位・人の話・外部への露出可否・お金 | **選択肢にして聞く**（3〜5件だけ） |
| **B. AI が閉じてよい** | もう直っている／重複／前提が変わって無効／期限切れで意味が消えた | AI が判断して閉じる。**閉じた理由を必ず残す** |
| **C. 手を動かせば終わる** | 台帳の退避・リンク切れ・文言修正・1行の実装 | その場でやってから閉じる |

**A に倒すのは「本当に社長でないと決められないもの」だけ**。迷ったら B/C ではなく A に置くが、
**1回のセッションで社長に出すのは最大5件**（それ以上出すと、今と同じ「積まれた山」になる）。
残りは次回に回す＝`ask` を打たなければ次回また候補に上がる。

## 社長への出し方

- `AskUserQuestion` で **A案／B案の二択＋今回は見送り**。「どうしますか」と丸投げしない。
- **必ず AI の推薦を添える**（2026-08-28 社長ご指示＝「A案/B案の二択＋私の推薦」）。
  「私は A だと思います。理由は◯◯です」まで書いて出す。社長は同意なら A、違えば B を選ぶだけ。
  **推薦の無い選択肢は、考える仕事を社長へ押し返しているのと同じ**＝それがこの滞留の原因だった。
  ただし**推薦には根拠（実測値・滞留日数・影響範囲）を必ず付ける**。無いなら推薦せず「材料が足りない」と言う。
- 1件ずつ、**何を決めれば何が動くのか**を1行で添える。滞留日数も出す。
- 出したら `python3 bin/pending-scan.py ask <key>...` で提示済にする（翌日また同じものを出さない）。

## 決まったあとの書き戻し（ここが要）

**他モードの台帳を横から書き換えない。** 所有しているモードが自分で閉じる。

1. 回答を、そのレーンの `from-president.md` の末尾へ追記する
   （`data/hp-loop/<site>/from-president.md`・`data/partner/from-president.md` 等）
2. `python3 bin/pending-scan.py decide <key> --kind <president|ai-close|do-now> --note "from-president.md へ記載"`
3. **次回の起動時に `python3 bin/pending-scan.py verify` を必ず流す**
   ＝決めたのに台帳から消えていない項目を洗い出す。**書いて終わりにしない**
   （[[feedback_writeback-to-source-of-truth]]）

## セッションを終えるとき

`bash bin/office-beacon.sh stop triage cmd-triage` — 机を消灯（stop し忘れても TTL で10分後に自然消灯）

## やってはいけないこと

- **取りこぼしを黙る**：`stats` が出す「表の行として取り出せなかった印 N件」を報告から省かない。
  この道具は**表の行だけ**を項目として扱う。箇条書き・地の文の中の印は人が読む必要がある。
- **本文を状態ファイルへ写す**：台帳には取引先名・案件の実体が入る。`state.json` は
  ID・置き場・日付だけを持つ。表示は毎回ソースから読み直す。
- **社長に大量に出す**：5件を超えたら、それは仕分けができていないということ。
- **推測で閉じる**：意図が読み取れないものは B ではなく A へ。
