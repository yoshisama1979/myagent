変更した内容をステージングしてください。

## 注意

- `git add .` や `git add -A` を**使わない**。必要なファイルだけ個別に `git add <path>` する
- **`.scss` を編集したら、コンパイルされた `.css` も一緒にステージする**（既定。配信・復元される実体は `.css` であり、`.scss` だけコミットするとリポジトリが公開中のサイトと一致しなくなる）。`git add` は `.scss` と対応する `.css` の**両方を個別パスで**指定する
- 差分が暴れる（プレフィックスが付いたり消えたりする・触っていない箇所が動く）場合は、**`.css` を外すのではなく生成系を一本化して解決する**（`.claude/rules/scss-autocompile.md` §4「ベンダープレフィックスの方針を一本化する」）。一本化が済むまでの暫定として `.css` を外す運用にしているプロジェクトは `project-config.md` にその旨が記入されているので、その方針に従う
- **`.scss` を編集したのに `.css` が更新されていない**場合はステージせず報告する（自動コンパイル環境が無い＝開発者にコンパイルを依頼する。AIは手動でビルドを叩かない・`.css` を手編集しない）
- `images/` 配下の大きなファイルや、`*.BAK` `index_org.html` 等のバックアップを誤ってステージしていないか確認する

## 完了後

ステージしたファイル一覧を `git status` で報告すること。
