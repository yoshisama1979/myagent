# 残存課題（pending-issues）

このファイルは、制作・実装・運用（SEO 改善を含む）の中で **その場で対応しきれず未解決のまま残った課題** の記録先。
すぐ対応できるものは対応し、そうでないものを取りこぼさないための仕組み（`CLAUDE.md`「残存課題の記録ルール」準拠）。

## 記録フォーマット

各課題は以下の3点を明記する：

- **経緯**: なぜこの課題が出たか／現状どうなっているか
- **未対応**: 何が残っているか（具体的に）
- **今後の判断ポイント**: 着手の判断材料・前提・あるべき手段

解決した課題はこのファイルから削除し、**確定仕様の記録先へ転記する**（行き先は `CLAUDE.md`「残存課題の記録ルール」が定める。仕様書を持つプロジェクトはその該当ページへ、そうでなければ確定事実・デザインの記録側へ）。
通し番号 `PI-NNN` は連番で続ける。
